Why it exists
mergekit combines models.
Everything else was scattered.

  
Abliteration scripts, ROME repos, Wanda, SparseGPT, QuaRot, LoRA tooling — each with its own conventions. weightkit puts them behind a single abstraction so they compose.

  

    
01
One Op abstraction
Every method is a registered class with typed parameters. A new method is ~20 lines. Single-model and multi-model ops are the same thing — so merge → abliterate → prune is a pipeline, not three tools.

    
02
Exact transforms, proven exact
Norm folding, Hadamard rotation, permutation, rescaling, SmoothQuant scaling, Re-Basin alignment — each is tested to leave logits unchanged, including on a real Hugging Face Llama.

    
03
Lazy, spillable, shared
Tensors load on demand; edits spill to temp safetensors past a memory budget. One calibration file feeds Wanda, SparseGPT, MEMIT, SmoothQuant and abliteration.

Pipelines
Compose them in YAML — or Python.

  
Each step runs on the shared store; calibration is collected once and reused.

  

    

      
pipeline.yaml


base: ./Llama-3-8B
calibration: ./calib.pt
output: ./out
steps:
  - op: merge            # TIES + DARE
    method: dare_ties
    density: 0.5
    sources: [{model: math, weight: 0.6}, {model: code, weight: 0.4}]
  - op: abliterate
    pos: harmful
    neg: harmless
    layer: 14
  - op: rotate           # exact outlier smoothing
  - op: prune
    method: sparsegpt
    nm: [2, 4]

    

    

      
Python


import torch
from weightkit import TensorStore, apply_op, Calibration

store = TensorStore.from_path("./Llama-3-8B")  # lazy
calib = Calibration.load("calib.pt")

apply_op(store, "prune", calib=calib,
         method="wanda", sparsity=0.5)
apply_op(store, "rotate", kind="hadamard")

store.save("./out", dtype=torch.bfloat16)

Trust, but verify
Tests assert behaviour, not just shapes.

  
74 tests, run against a pure-torch tiny Llama and a real transformers.LlamaForCausalLM.

  

    
✓
Exact ops keep logits unchanged: fold_norm, rotate (incl. non-power-of-two & biased models), permute, rescale, smooth_scale, align, kv_pool on duplicated heads.

    
✓
Abliteration: the target direction's component is ≈ 0 at the embedding and after every layer's output.

    
✓
Editing: ROME hits its target in a real forward pass with a rank-one update; steering shifts the residual by exactly scale·v.

    
✓
Pruning: SparseGPT beats magnitude on correlated inputs (0.26× error), N:M patterns exact, Wanda protects hot channels.

    
✓
Maths: SVD truncation matches Eckart–Young, LoRA extract→merge round-trips, DARE is unbiased, TIES elects signs correctly.

    
✓
Systems: sharded save/load, tensor sharing, memory spilling and full YAML pipelines round-trip.

  

  
Honest limitations
    
    
  • Llama-family tensor naming only (Llama, Mistral, Qwen2/3, Yi, SmolLM…). No fused-QKV (Phi-3), MoE, or Gemma-2/3 yet.
    • 
    
  • Verified on tiny models and a tiny HF Llama — not yet on multi-billion-parameter checkpoints.
    • 
    
  • edit_facts is the closed-form half of ROME/MEMIT: you supply target values; automatic v* search isn't implemented.
    • 
    
  • quantize_rtn writes dequantized weights; it isn't a packed GPTQ/AWQ export. Nothing here evaluates model quality.
    •
